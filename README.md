# Skanda Traders React Website

Premium React + Vite single-page website for Skanda Traders, Puducherry.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:

```bash
http://localhost:5173
```

## Production build

```bash
npm run build
npm run preview
```

## Important files

- `src/App.jsx` - section order and floating WhatsApp button
- `src/components/` - website sections
- `src/data/products.js` - product categories and product story data
- `src/App.css` - full responsive styling
- `src/assets/skanda-traders-logo.jpg` - supplied logo asset
